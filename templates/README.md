# SISMED

## Sistema de Gestión Médica

SISMED es una aplicación web desarrollada para optimizar la gestión
de pacientes, médicos, citas e historias clínicas del Consultorio
Los Rosales.

## Tecnologías

- Python
- FastAPI
- SQLAlchemy
- SQLite
- HTML
- CSS

## Módulos

- Login
- Dashboard
- Pacientes
- Médicos
- Citas
- Historias clínicas
- Enfermería
- Reportes
